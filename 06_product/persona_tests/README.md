# Persona Testing

**These are not real users.** Each persona is a virtual identity played by an AI. It writes its own set of synthetic meetings that fit that identity, first writes down a real task list, then operates the running product through a real browser, and submits feedback through the product's built-in feedback entry point.
So this testing can show that the product is usable, surface bugs, and quantify how the model performs across different meeting formats. It cannot show real demand, real retention, or real time saved.
